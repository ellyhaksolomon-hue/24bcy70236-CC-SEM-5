# LeetCode 328: Odd Even Linked List

## Problem Statement

Given the head of a singly linked list, group all the nodes with odd indices together, followed by the nodes with even indices, and return the reordered list.

The first node is considered to have index `1`, the second node index `2`, and so on.

Please note that the relative order inside both the odd and even groups should remain the same.

You must solve the problem in `O(1)` auxiliary space complexity and `O(N)` time complexity.

### Example 1

**Input:**
```text
head = [1,2,3,4,5]
```

**Output:**
```text
[1,3,5,2,4]
```

**Explanation:** Nodes at odd positions (`1, 3, 5`) appear first, followed by nodes at even positions (`2, 4`).

### Example 2

**Input:**
```text
head = [2,1,3,5,6,4,7]
```

**Output:**
```text
[2,3,6,7,1,5,4]
```

**Explanation:** The odd-indexed nodes are `[2,3,6,7]`, and the even-indexed nodes are `[1,5,4]`.

## Solution (Python)

```python
class Solution:
    def oddEvenList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        odd = head
        even = head.next
        even_head = even

        while even and even.next:
            odd.next = even.next
            odd = odd.next

            even.next = odd.next
            even = even.next

        odd.next = even_head

        return head
```

## Approach

The solution uses **in-place linked-list manipulation** to group odd-indexed and even-indexed nodes.

1. If the linked list is empty or contains only one node, return it unchanged.
2. Initialize `odd` to the head and `even` to the second node.
3. Store the beginning of the even-indexed list in `even_head`.
4. Connect the current odd node to the next odd-indexed node.
5. Move the `odd` pointer forward.
6. Connect the current even node to the next even-indexed node.
7. Move the `even` pointer forward.
8. Repeat until no more pairs of nodes are available.
9. Connect the end of the odd list to `even_head`.
10. Return the original head.

This method preserves the relative order of nodes in both groups without creating additional linked lists.

## Complexity Analysis

### Time Complexity: O(N)

Each node is visited and processed at most a constant number of times. Therefore, the time complexity is `O(N)`, where `N` is the number of nodes in the linked list.

### Space Complexity: O(1)

The algorithm uses only a few pointer variables, such as `odd`, `even`, and `even_head`. It does not create any additional data structures proportional to the input size.

Therefore, the auxiliary space complexity is `O(1)`.
